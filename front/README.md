# Frontend Red TeleCorp
Sitio estático (HTML + JS, sin build). El API se configura en la constante `API` al inicio de `index.html`.

## Despliegue en Cloudflare Pages
1. Cloudflare Dashboard > Workers & Pages > Create > Pages > Connect to Git.
2. Repo `RedTelecorp`, rama `main`.
3. Build command: (vacío). Build output directory: `front`.
4. Save and Deploy. La URL queda en `https://<proyecto>.pages.dev`.

Cuentas demo: usuario@telecorp.com / user123, operador@telecorp.com / tech123, admin@telecorp.com / admin123
